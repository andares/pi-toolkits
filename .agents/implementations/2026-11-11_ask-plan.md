## 值得记下来的几件事

1. **WSL 下的浏览器不是"细节"**：实测 Windows 连不上绑在 `127.0.0.1` 的 WSL 服务，也连不上
   `localhost:<port>`；必须绑 `0.0.0.0` 且 URL 用 eth0 地址，并用 `cmd.exe /c start` 交给 Windows。
   本机存在 `/usr/bin/google-chrome`，`xdg-open` 正是"开出看不见的浏览器"的元凶。
2. **`window.close()` 够用**：plannotator 的做法是调用后 300 ms 检查 `window.closed`，没关掉才显示
   提示。我们照做，不弹倒计时、不问用户。
3. **diff 的诚实性**：先按同 id 做 LIS 取锚点，再对剩余块按字符二元组 Jaccard 配对成"已修改"，
   位置变化记"移动"。否则"改三个词"会显示成"删一段 + 加一段"，评审徽标就没人信了。
4. **permission 需要控制面**：`/ask-perm` 的状态在闭包里，新增 `src/lib/permission-control.ts`
   注册表（与 `startup.ts` 同款），计划期用它开关并恢复。
